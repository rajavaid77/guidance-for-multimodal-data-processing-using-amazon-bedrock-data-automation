# MP-210 Medical and Surgical Supplies
Applies to: all AnyHealth plans · Synthetic demo policy · Codes: A4206-A8999

- Supplies are covered when used in a covered treatment and not already included in the procedure payment.
- Supplies used in a physician office during a procedure are generally bundled into the procedure (CARC 97) unless
  the code is listed as separately payable.
- A4223 (infusion supplies without external pump) is covered only with covered home infusion therapy; prior
  authorization applies under AnyHealth Standard.
- A4649 (miscellaneous surgical supply) requires the item description in the shaded supplemental area of item 24 or
  item 19, and a manufacturer invoice. Without a description the line is pended (CARC 16, RARC M124).
